# 定局秘书查表（dingju-mishu）

袁家祖传手抄本《袁天罡大六壬定局秘书》中六张「按生辰直接查」的表，做成一个免费的
[Agent Skill](https://docs.claude.com/en/docs/agents-and-tools/agent-skills/overview)，也能当命令行小工具用。
输入出生时间与性别，查出原书的诗句与页码。书和祖父「袁天师」的故事见 [STORY.md](STORY.md)。

## 六张表

| 表 | 查法 | 原书 |
|---|---|---|
| 六十甲子生人 | 年柱（立春换年）→ 禽象与性情，如「庚午生人乃为追风之马」 | P12、P2–18 |
| 出世吉日 | 农历日：太阳／太阴／天父／天母／天帝／天皇，六日一轮 | P19–21 |
| 生时初中末定命 | 时辰主星（玉皇、白帝、贵元……），再分上中下三刻 | P62–70 |
| 男女花园宫 | 农历生月 × 生时 → 十二宫（子息），正月长生在寅 | P73–85 |
| 查流年例 | 流年地支从本命年支起数：太岁、太阳、丧门……病符 | P156–162 |
| 值命星 | 九曜按虚岁九年一轮，男起罗睺、女起计都，附原书禳法 | P170–175 |

**有意不收**：画符治病、小儿关煞、寿数与身后事。原因见 STORY.md 末节。

## 安装

作为 Claude Code 技能：把整个目录放到 `~/.claude/skills/dingju-mishu/`。依赖：

```bash
pip install lunar_python
```

## 命令行

```bash
python3 scripts/dingju.py --birth "1990-06-15 08:30" --gender male --longitude 116.41
python3 scripts/dingju.py --birth "1990-06-15 08:30" --gender female --json
python3 scripts/dingju.py --selftest
```

| 参数 | 说明 |
|---|---|
| `--birth` | 出生地钟表时间 |
| `--gender` | `male` / `female`，值命星男女起星不同 |
| `--longitude` | 出生地经度；给出则按真太阳时排（经度时差＋均时差） |
| `--tz` | 出生时当地时区，默认 8 |
| `--sect` | 晚子时（23–24 点）：2＝日柱算当日（默认），1＝算次日 |
| `--today` | 以哪天定流年与虚岁，默认今天 |

## 准确性

- 诗文逐字对照原件扫描图核过。抄本俗写按文意规范为通行简体；〔〕为整理者校订，□ 为原书难辨之字。
- `--selftest` 的期望值一律取自原书自己的表（出世吉日表、花园宫表、流年表、值命星行年表）。
- 与「循禽纪」App 中同一套实现在 500 组随机生辰上逐项一致。
- 年柱以立春换年，虚岁以农历正月初一计；上中下刻原书未说分法，这里把一个时辰三等分；
  均时差用三角近似式，误差约半分钟。
